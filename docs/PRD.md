# PRD · 产品需求文档

> 版本 v3.0 ｜ 2026-10-29 ｜ 状态：已上线

## 1. 定位

一个**个人投资决策系统**：把已经验证过的年度动量策略固化下来，让用户每天只需回答一个问题——
「今天该做什么」——并且能在 3 秒内得到答案。

不做交易执行、不做组合记账、不做社区。**只做决策与跟踪。**

## 2. 目标用户

| 画像 | 特征 | 关键诉求 |
|---|---|---|
| 主业不是金融的上班族 | 没时间盯盘，容易追涨杀跌 | 一年只操作一次，日常不用管 |
| 有一定资金但缺乏纪律 | 知道该长期持有，做不到 | 有明确规则与「持有不动」的确认感 |
| 想验证策略是否成立 | 看过很多"年化 30%"的宣传 | 能看到逐年、回撤、失败年份 |

**非目标用户**：日内交易者、需要多策略组合的人、需要实时下单的人。

## 3. 用户故事

### 3.1 每天看一眼（高频，占比 90%）

> **US-1** 作为持有该策略的上班族，我早上打开手机，想**一眼知道今天要不要动**，
> 这样我不必读任何解释文字。
> **验收**：首屏出现「结论」（持有不动 / 12 月末换仓），字号为全页最大；下方一行持仓摘要；
> 结论为「持有不动」时不出现任何操作按钮（除"看账户"）。

> **US-2** 作为用户，我想知道**今天涨跌多少**，这样我能感知当天市场。
> **验收**：显示「今日 ±x.xx%（±$N）」；行情超过 45 分钟未更新时标注「截至 HH:MM」并注明「盘中，未计入累计」；
> 涨用红、跌用绿（大陆习惯）。

> **US-3** 作为用户，我想确认**数据是不是今天的**，这样我不至于看着过期数据做决定。
> **验收**：页面固定显示「净值 MM-DD HH:MM（北京）」，且与 `equity.updated` 一致。

### 3.2 年度换仓（低频，占比 5%）

> **US-4** 作为用户，12 月末我想知道**明年该买哪三只、各多少钱**。
> **验收**：显示 3 只代码、行业、权重、入选涨幅；显示「建仓日」与「生效区间（2026-01-01 ~ 2026-12-31）」；
> 显示「下次换仓：2026-12 最后一个交易日」。

> **US-5** 作为用户，我担心**选股被事后修改**，这样我就无法相信历史记录。
> **验收**：当年持仓在换仓日锁定后不可漂移（`official_locks.json`），自检发现漂移即阻断部署；
> 页面显示锁定月份。

### 3.3 验证策略（中频，占比 5%）

> **US-6** 作为用户，我想看**长期是否成立**，这样我才敢把钱放进来。
> **验收**：显示 2010–2025 累计收益、年化、最大回撤、胜率；提供逐年表（年度收益、年内回撤、当年持仓）。

> **US-7** 作为用户，我想知道**最坏情况**，这样我能承受得住。
> **验收**：最大回撤单列且用跌色；分年表标出亏损年份；口径写明「年内谷底」。

> **US-8** 作为用户，我想**核对当期与长期不是一个数**，这样我不会把 105% 当成 16 年累计。
> **验收**：当期用「2026 年策略收益」，长期用「全周期累计收益（2010–2025）」，两者不得同名。

## 3.5 双口径（A / B）

同一策略有两种排名池定义，页面用 Tab 切换、数据各自独立：

- **A 时点成分**：排名日当天在指数内即可。
- **B 全年成分**（默认）：上一年整年都在指数内，排除中途纳入/剔除的股票。

差异会体现在持仓与逐年回测上（例如 2026 年度：A 为 WDC/MU/HOOD，B 为 WDC/MU/WBD）。

## 4. 功能清单

| 模块 | 功能 | 状态 |
|---|---|---|
| 今日卡 | 结论、今日涨跌、大盘开关 | ✅ |
| 当期卡 | 年收益、本金切换、市值/盈亏/成本/仓位 | ✅ |
| 持仓卡 | 代码、市值、涨跌、盈亏（建仓价/现价小字） | ✅ |
| 预览卡 | 次年可能持仓（年初至今涨幅，年末定稿） | ✅ |
| 全周期卡 | 累计/年化/回撤/胜率 + 双曲线 + 图例 | ✅ |
| 逐年卡 | 16 年持仓、收益、回撤 | ✅ |
| 数据 | 每日行情、当前信号、当期净值、历史锁定 | ✅ |

## 5. 信息架构

```
单页为主：顶部结论 → 当期（金额）→ 持仓 → 次年预览 → 全周期（比例/长期）→ 逐年明细
```

三层时间视野，命名强制区分：

| 层 | 命名 | 示例 |
|---|---|---|
| 远期 | 全周期 + 指标 | 全周期累计收益 5059% |
| 中期 | {年份} + 指标 | 2026 年策略收益 +104.72% |
| 当下 | 今日 | 今日 -1.44%（-$1,442） |

## 6. 设计原则

1. **少就是多**：同一指标全站只出现一次；不解释过程，只给结论与数字。
2. **红涨绿跌**：符合大陆用户习惯，不跟随欧美配色。
3. **深色 + 暖金**：`#080A0F` 底、`#F2C46B` 强调，数字用等宽字形。
4. **响应式**：移动端单列（390px 无横向溢出、触控 ≥44px）；桌面 ≥1000px 双列栅格，标题与数字同步放大。
5. **不出现元信息**：不写"本页面由…生成""与某页同一口径"，只留必要口径与免责声明。

## 7. 非功能需求

| 项 | 要求 | 现状 |
|---|---|---|
| 数据新鲜度 | 美股收盘后 1 小时内更新 | 盘中每 5 分钟触发 |
| 可用性 | 静态站，无后端依赖 | GitHub Pages |
| 首屏性能 | 无框架、单文件 JS | ~200KB |
| 数据正确性 | 部署前 78 项硬校验（含 20+ 项口径 B 专项） | 全绿 |
| 可回溯 | 任一天数字可复算 | 部分（见 KNOWN_ISSUES） |

## 8. 验收标准（发布门槛）

1. `selftest.py` 78/78 通过。
2. `consistency_check.py` 22/22（A/B 两口径各跑一遍）、`audit_b.py` 180/180 通过。
3. 三页的当期收益必须等于 `equity.stats.strategy`（误差 <0.05%）。
4. 移动端横向溢出为 0，无 JS 报错。
5. 当年持仓与 `official_locks.json` 一致。

## 9. 不做的事（明确边界）

- 不做用户系统与持仓录入（账户是理论账户，所有人看到的一致）。
- 不做下单、不做券商对接。
- 不做多策略对比、不做参数调优界面。
