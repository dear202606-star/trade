报表市值以整美元展示，因此使用保守 ±1 美元区间核对股份单位，不把市值/股数伪装为另一条精确收盘报价。实际价格仍须与明确日期的两个行情来源核对，再完成在线价格和验收证据登记。报表脚注 (a) 为部分证券出借，(b) 为非派息证券，未据此改变股份单位。

解析器目前得到 494 个候选行，并非完整、已验收的股票池：长名称换行、其他资产类别、名称/股份类别映射均须继续检查。只有上述两个精确名称得到单位区间核对；未修改数据库或已发布结果。源码为 research/audit_fund_native_units.py，机器回执为 output/fund_native_unit_review.json。PDF 仅从本地已固定哈希缓存读取，发生变化会拒绝，不自动刷新。

## 已排除的日期陷阱

- SEC 搜索结果中的 repPdEnd 可能是基金财政年度终点，例如 2025-12-31；另一个字段 repPdDate 却是实际持仓日，例如 2025-09-30。不能只匹配前者。
- 发行人公开 latest-holdings.csv 加 asOfDate=20251231 参数后，实际表头仍返回 2026-11-02。本次请求响应哈希为 f87992fb55584a7f2d0dfa31765da5d4598de83c18f24f25282ade1834caaf6b，明确拒绝用于 2025-12-31 数据；不凭 URL 参数认定日期。
- 原始 NPORT XML 和另一个基金 PDF 的直接下载返回 403，没有尝试绕过，也没有当作有效原始文件保存。

发行人持仓页面说明，持仓价格可能是最近可用供应商价格，未必就是表头当天价格。因此持仓报表只作证券身份、股份和金额单位佐证，不能单独批准收盘价或全收益序列。候选日期、股类、货币、原始行情、公司行动和完整覆盖仍须分别验收。
