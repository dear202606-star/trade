范围：当前单页总览及跳转到总览的旧入口，A/B 口径、分时当前报价、日收益、年度收益、持仓、次年预览、质量提示、定时工作流和看门狗。不包含不存在的分钟历史曲线功能。

## 已定位及本轮修复

| 问题 | 根因 | 修复与验证 |
|---|---|---|
| 报价正常但今日收益空白 | 在线行情独立刷新；静态收益基准落后多个交易日，安全衔接检查拒绝计算 | 区分读取失败、时效未知、基准落后和价格单位待核验；保留拒绝跨日猜算规则 |
| 次年预览看似当前前三 | 页面只请求行情，旧预览始终被重复渲染；没有检查报价版本和资格证据 | 每分钟刷新依赖；要求同报价版本、同场次、参考版本、三项结果和有效期，否则隐藏排名并显示上次计算时间 |
| 报价版本不变时错过更新/过期 | 渲染与新报价版本绑定 | 不论版本是否变化均读取依赖、重绘、检查有效期 |
| 持仓明细与账户总额口径不同 | 明细单独用原始入场价比例拼接最新报价，绕过账户统一校验 | 明细统一使用账户校验后的价格；过期报价不允许桥接年度收益 |
| 初次加载失败不会恢复 | 自动刷新在首次成功分支中启动 | 初始失败也启动重试；A/B 异步响应不得覆盖另一口径 |
| 行情请求失败仍留旧 SPY 数值 | 渲染函数在缺报价时直接返回 | 清除旧数值、显示读取失败及重试状态 |
| 质量状态夸大 | 仅凭 degraded=false 就显示全收益口径100% | 检查失败数和各项状态；只描述实际检查；读取失败明确提示 |
| 看门狗遗漏下游停滞 | 只检查行情任务和静态健康报告 | 新增两种口径收益基准与预览依赖检查，和行情工作状态分别告警 |

## 未完成，不能宣称全链路恢复

每日全量工作流中选股校验失败会阻断其后的净值与预览生成。必须建立独立增量计算与在线发布路径：已核验持仓/单位基准在线固化；仅采集新增场次，逐个验证拆股、分配、分红及后继资产；原子发布带依赖版本的收益结果。禁止取消日期或单位校验来消除空白。

次年排名必须使用完整候选全集与已核验的身份、资格、原始价格、企业行动和流动性证据。P 等历史身份或价格缺口未解决前，不得缩小候选池或沿用旧榜冒充当前动态前三。当前页面会明确拒绝展示这类结果，看门狗应报告未恢复。

新增检查可以发现和阻止静默错显，不能保证外部源永不失败。最终验收还需实际独立任务成功、在线结果依赖对账、失败后自动恢复、桌面/手机复核及连续多个真实交易场次运行证明。已验收历史保持只读。
