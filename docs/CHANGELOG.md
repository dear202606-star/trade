## v4.0 ｜ 2026-10-31 ｜ 修复净值停滞（交易日历以持仓为准）

**问题**：净值与当期收益停在上一交易日（10-29），而个股行情已到 10-30。
根因是 equity.py 的交易日历**只用 SPY 日线**，而新浪 SPY 偶尔比个股晚一天更新 —— 整条曲线因此不前进，
表现就是「收益数字不会自动变化」。

**修复**：
- 交易日历改为「持仓股票日期的并集」，基准 SPY 缺失时用前值回填。
- 新增门禁：净值必须跟上最新收盘交易日（last_session ≥ quotes.session）。
- DSH.today 的盘中/收盘判断改用 quotes.intraday（不再用「45 分钟内」猜测），
  收盘后页脚正确显示「收盘」，也不会把当天涨跌重复叠加。

## v3.8 ｜ 2026-10-30 ｜ 修复前端脚本被缓存

**问题**：bust_cache() 只给 app.css / app.js 加版本号，page.js 与 page.css / 	heme.css
始终以无版本号的方式被引用 —— 浏览器会一直用本地缓存的旧脚本，所以「当期收益盘中实时」这类
改动上线后，老用户看到的仍是旧行为。

**修复**：
- 版本哈希覆盖 app.css、app.js、page.css、page.js、	heme.css。
- 所有页面引用统一带 ?v=<哈希>，脚本一改哈希就变，浏览器必然重新拉取。

## v3.7 ｜ 2026-10-30 ｜ 当期收益改为盘中实时

**问题**：当期收益只按「已收盘交易日」计算，盘中一直显示昨天的数字，而「策略今日表现」在实时跳动 —— 两者脱节，看起来像不更新。

**修复**：
- quotes.py 新增 intraday 标志（美东 09:30–16:10 工作日为 true）。
- 页面在盘中用 (1 + 收盘收益) × (1 + 今日涨跌) − 1 展示当期收益，并注明「含今日 −5.61%（收盘 +99.45%）」；
  收盘后自动回退到收盘值，避免重复计算。
- 总市值 / 累计盈亏同步为盘中口径，与「今日」一致。
- 一致性检查按口径分别校验：盘中用叠加公式，收盘用净值。

**自动化巡检结论**（逐项）：
| 元素 | 更新频率 | 状态 |
|---|---|---|
| 顶栏 SPY / 涨跌 | 每 5 分钟 | ✅ |
| 策略今日表现 | 每 5 分钟 | ✅ |
| 当期收益 / 市值 / 盈亏 | 每 5 分钟（盘中叠加） | ✅ 本次修复 |
| 仓位建议 / 均线 | 每次运行 | ✅ |
| 当年策略明细 | 每 5 分钟 | ✅ |
| 次年策略预览 | 每 5 分钟 | ✅ |
| 历史收益回测 / 逐年明细 | 收盘后（日频） | ✅ 设计如此 |
| 下次换仓日期 | 年度结转时 | ✅ |

第四路审计（独立重算）发现输入数据层缺陷，修复其中可离线修复的两项：

**伪拆股**：新浪日线对部分票已是拆股后价格，再乘一次因子会造出 +99%~+177% 的假月涨幅。
新增 _valid_splits()：用「原始价是否按比例下跌」校验拆股事件，不一致则跳过。
影响：2015 年 65.34% → 23.99%；2016/2019/2021 年选股随之改变。

**幸存者偏差**：行业表只覆盖 513/1209 只（只有 2026 年仍存续的票有分类），
旧实现把「行业未知」整体剔除 → 2010 年实际只有 34% 的池子参与排名。
改为「未分类」单独成桶、每年前 3 最多 1 只，不再整体剔除。

**异常过滤**：|ret12| > 500% 视为价格损坏（此前 PCL/GAS/HAR 有 4~5 位数假涨幅）。
