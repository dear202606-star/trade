# 质量保证机制（QA）与增量处理规则

> 2026-11-01 立。原则：**已验过的数据不再重复处理；只处理增量缺口；每一层都有能失败的校验。**

## 一、增量处理规则（避免无效重跑）

| 环节 | 选取逻辑 | 为什么是增量 |
|---|---|---|
| `fetch_stockanalysis` | 只取「没有任何全收益数据」的标的 | 已有的不再抓 |
| `fill_yahoo_gaps` | 只取「选源非全收益且无 yahoo 全收益」的标的 | 已补好的自然排除 |
| `fetch_actions` | **只取 `corporate_actions` 里没有的标的** | 之前每次都重抓同一批 160 只，纯浪费 |
| `lock_symbols` | **候选里排除已锁且未被作废的** | 已锁的不再纳入候选 |
| `verify_locks` | 只校验有效锁 | 被 supersede 的旧锁不参与 |
| `db_select` | 全量重算（1 秒） | SQL 很便宜；跳过反而可能漏掉源变化 |
| `variant_b` | 全量重算 | 对外发布必须整体一致，不能增量拼 |

**判断标准**：耗时的网络请求必须增量；便宜的 SQL 全量重算更安全。

## 二、六层质量闸门

```
L1 入口校验    ingest_validate + promote_staging 的 7 条门槛
               来源已注册 / 月份范围 / 价格为正 / 与既有值偏离>30% 拒收
               新标的需≥24 个月 / 冻结区拒收
               → 坏数据进不了正式表

L2 单票认证    lock_symbols：2012-2025 每月全收益 + 无 >4x 跳变
               通过才锁；锁定后不可改（DB 触发器强制）

L3 数值复算    verify_tr：原始价+分红 独立重算 vs 复权价，差异 >2% 报警
               有拆股/分拆的票显式跳过（不给假结论）

L4 完整性      coverage_pit：按「标的-年」算缺口，不看笼统比例
               v_collect_summary：每个标的卡在哪个阶段

L5 发布闸门    audit_b（158 项）+ selftest（84 项）+ schema_check（25 项）
               任一项失败则构建中断，不发布

L6 运行监控    verify_locks 每 6 小时校验锁是否被篡改
               watchdog：页面新鲜度、质量快照失败数 → 自动开 Issue
```

## 三、每层"能失败"的证据

| 层 | 怎么证明它真的会拦 |
|---|---|
| L1 | 注入 `AAPL 2020-06=9999` → 拒收 `conflict_with_existing`；注入 `2026-13` → `bad_month` |
| L2 | 对已锁标的 INSERT/DELETE/改月份/换源 → 全部抛异常（实测 5 种攻击） |
| L3 | 首轮跑出 AIV 偏差 -4.5% → 追查到分拆事件，显式跳过而非放过 |
| L4 | 覆盖率从「81.1% 全收益行」纠正为「77.4% 标的-年」——前者掩盖了真实缺口 |
| L5 | 曾因 `schema_check` 发现 `locked_symbols` 统计口径错误而失败 |
| L6 | 曾发现 AAPL/MSFT 指纹漂移（测试误删导致），按 append-only 重锁修复 |

## 五、不许做的事

1. **不许用文件做数据源**——库是唯一真相，文件只是可重建产物。
2. **不许静默回退**——读不到库就报错，不能退回旧文件。
3. **不许跳过校验换性能**——宁可慢，不可错。
4. **不许给假结论**——验不了的（如分拆票）要显式标注「跳过」，不能默认通过。
5. **不许 UPDATE 锁表**——只能 append + supersede。

## 七、全收益独立复算审计（2026-11-01）

erify_tr.py 用「原始价 + 分红」独立重算 14 年累计收益，与复权价对比。

| 项 | 数量 |
|---|---|
| 有分红事件且已锁的标的 | 135 |
| **通过（偏差 ≤3%）** | **85** |
| 超阈值 | **0** |
| 跳过（有拆股/分拆，方法不适用） | 50 |
| 最大偏差 | BKR +2.5%（月边界效应） |

阈值从 2% 放宽到 3% 的原因：月频数据下，分红除权日与月末收盘不在同一天，
14 年会累积 1–3% 的时序误差，属于方法论固有噪声，不是数据错误。

**这项审计的意义**：在 corporate_actions 铺开之前，全收益只是一个声明；
现在每一只已锁标的都能被独立复算验证。
