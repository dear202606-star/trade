# 正式站数据刷新清单

表内时间为北京时间。美股交易日收盘后约 45 分钟开始采集，正常情况下全部数据更新一次。工作流排队和数据源核验会增加等待时间。

| 网页数据 | 采集与计算 | 页面刷新 |
| --- | --- | --- |
| SPY 收盘价、涨跌幅、大盘仓位信号 | 核验收盘行情后更新。仓位信号使用 SPY 收盘价与 10 月均线。 | 打开页面时读取。顶栏统一显示美股交易日期。 |
| A/B 单日与当年策略表现 | 用同一场收盘数据计算单日收益、年初至今净值、同期标普和持仓表现。 | 收盘结果发布后更新。修改模拟本金时，金额立即重算。 |
| A/B 次年策略预览 | 同场收盘后计算候选股年初至今收益率并重排前三名。 | 收益率与排名一起更新，收益率保留两位小数。 |
| 策略历年效果 | 已发布的 A/B 历史曲线、历年收益与回撤封存。 | 首次打开页面或切换到另一策略时读取。 |

常规采集启动时间为夏令时次日 **04:45**、冬令时次日 **05:45**。提前收盘按交易所日历补采，休市日沿用最近一次结算。收盘窗口内，已打开的页面约每 15 分钟检查一次发布版本。其余时段保留最近一次收盘结果。数据缺失时会自动补跑，已完成结算时跳过。

GitHub Pages 仅在代码变更或手动发布时重新部署。每日结果通过在线数据源更新。
