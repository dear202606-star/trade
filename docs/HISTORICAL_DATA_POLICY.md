# 历史数据保存规则

用户于 2026-11-03 明确：历史数据校验无误后永久保存，不再自动刷新、重新采集或加工。

- 正式数据及验收证据保存在线数据库；本地回执只供审查。
- 完整验收通过后锁定数据版本、证券身份、时间范围、单位及证据。后续任务只读该版本，跳过对应采集与加工。
- 新增月份和未通过的历史缺口继续补齐；单个组件通过不代表整个年度已验收，不提前锁定未通过区间。
- 代码或供应商变化不能自动触发对已验收历史的重采、重加工或覆盖。若发现问题，记录问题并交由用户决策，不静默改写。
- 锁定校验失败不得使用强制参数放行。现有不可变证据和数据库锁守卫继续保留。

当前完整年度仍有待验收项，不能据此宣称全历史已经锁定。后续需要逐一核对各采集入口是否遵守跳过规则，并验证已验收版本在代码升级后仍能只读使用。

锁定入口已实现：相同历史区间存在已锁定记录时，仅查询并返回，不再调用度量/校验加工，也不更新原哈希或验收时间；并发情况下的冲突写入同样保留原锁记录。校验失败（包括强制参数）不能创建锁。相关回归已加入持续测试。此项不替代其他采集入口的跳过规则审查。
